# UKUDLA Introduction to Data Science — Course Material

Welcome! 👋

This repository contains the **public learning material for the Introduction to Data Science course**.

The material is organized into ten topics and accompanies the more general presentation slides and the more detailed guideline pages of the course.

## 📚 Course Material

The content in this repository is the published version of the course material.

You are welcome to:

* browse and download the material,
* use it while working through the course,
* report errors or unclear explanations,
* suggest improvements,
* and discuss the material with other learners.

The current commit contains the same state of the file published in the learning module so you use this repository to track the versions of the material of the learning module. 

## 💬 Feedback and Discussions

Feedback is very welcome!

We use **GitHub Discussions** to collect questions, comments, corrections, and suggestions about the course material.

There is a dedicated discussion for each of the ten course topics.

If you have feedback, find the discussion corresponding to the topic you are working on and add a comment there.

Feedback can include, for example:

* 🐛 **Errors** — something appears to be incorrect.
* 🤔 **Unclear explanations** — a concept or example was difficult to understand.
* ✏️ **Suggestions** — you have an idea for improving an explanation or example.
* 💡 **Additional examples** — another example might make a concept easier to understand.
* 🔗 **Resources** — you know of a useful resource that complements the material.
* ❓ **Questions** — something in the material raised a question.

When commenting, please mention the **page, section, exercise, or file** you are referring to whenever possible.

### 👍 React to existing feedback

Before adding new feedback, have a quick look at the existing comments.

If somebody has already raised the same point, you can add a **👍 reaction** to their comment instead of repeating it.

This helps identify issues or suggestions that are relevant to several learners.

## 🛠 How the material is maintained

This repository contains the **published version** of the course material. The original source material is maintained separately and used to generate the content published here.

For this reason, please use **GitHub Discussions rather than editing the files in this repository directly**.

Suggestions and corrections from the discussions are reviewed and, where appropriate, incorporated into the source material. The updated material is then generated and published here again.

In short:

```text
Course source
     ↓
Published material (this repository)
     ↑
Your feedback via GitHub Discussions
```

## ❤️ Contributions

Feedback from learners is an important part of improving this course.

If you find something confusing, incomplete, or incorrect, please say so. What seems like a small observation may help make the material clearer for many future learners.

Thanks for helping improve the course!
